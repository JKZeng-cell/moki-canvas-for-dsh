# MOKI Canvas for DSH · 项目简介

## 中文短简介

MOKI 白板 for DSH 是一款本地优先的无限画布插件，将绘图、思维导图和素材整理融入 DeepSeek Harness 侧边工作区。选中画布内容即可加入对话，也能让 DSH 直接读取与编辑白板，让想法从讨论走向可视化成果。

## 中文完整简介

MOKI 白板 for DSH（MOKI Canvas for DSH）把一张可编辑的无限画布放进 DeepSeek Harness。便签、文字、图形、连线、图片、文件、音视频和多页面，让灵感、参考与计划在同一处汇合。原生思维导图支持调整节点宽度、折叠分支和批量添加；紧凑界面跟随 DSH 深浅色主题，给画布留下更多空间。

白板和 DSH 可以双向协作：你可以让 DSH 创建、读取、修改、排版和导出内容，也可以选中画布中的一部分，点击输入框旁的“加入对话”，将文字引用和截图放入草稿，再决定何时发送。内置六页可编辑简介，以“星空露营短片”为线索，带你实际体验绘图、脑图、素材与 AI 协同。白板保存在本机，无需另行配置 MCP 服务。

## Short English description

MOKI Canvas for DSH is a local-first infinite canvas that brings drawing, mind maps, and media organization into the DeepSeek Harness side workspace. Add selected canvas content to a chat, or let DSH read and edit your boards to turn ideas into visual work.

## Full English introduction

MOKI Canvas for DSH puts an editable infinite canvas inside DeepSeek Harness. Bring notes, text, shapes, connections, images, files, audio, video, and multiple pages together in one place. Native mind maps support adjustable node widths, collapsible branches, and batch creation. A compact interface follows DSH's light and dark themes, keeping more space available for your ideas.

Collaboration works in both directions. Ask DSH to create, read, edit, arrange, or export board content, or select part of the canvas and click Add to chat beside the composer. The selection becomes a text reference and a screenshot in your draft; you decide when to send it. A six-page editable introduction uses a camping-film project to demonstrate drawing, mind maps, materials, and AI collaboration. Boards stay on your device, and no separate MCP server configuration is needed.
