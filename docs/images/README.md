The media kit also includes [bilingual project introductions](../project-introduction.md) and a [Chinese Xiaohongshu post with a suggested image sequence](../xiaohongshu-post.md).

The two cover illustrations were made with the built-in imagegen tool. Both use a charcoal background and a compact brand row: the original rounded-square MOKI icon, with its lavender-to-violet background and outlined white hand, beside the DeepSeek Harness whale/wordmark/badge. Logo references are `vendor/moki/public/moki-whiteboard-icon.png` and the host application's bundled `renderer/assets/welcome-brand.svg`. See [cover prompts](../cover-prompts.md).

All eight interface images are 1920 × 1080 direct Playwright captures of the real plugin in a clean DSH profile, with the dark DSH shell, sidebar and composer visible. They use only the bundled camping-film introduction and unsent demo drafts. They are not generated UI mockups. No personal boards, conversations, accounts or machine paths are shown.
