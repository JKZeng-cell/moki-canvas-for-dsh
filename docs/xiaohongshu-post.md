# 小红书发布文案

## 标题

给DeepSeek装上一张白板

## 正文

把 MOKI 白板做成了 DeepSeek Harness（DSH）插件，英文名叫 MOKI Canvas for DSH。打开后，白板就在对话旁边，一边聊想法，一边把它们画出来 🖐️

便签、绘图、思维导图、图片和音视频，都能放进同一张无限画布。做选题策划、整理参考、拆解项目，素材和思路可以摆在一起看，还能用多页面和分组慢慢整理。

最想分享的是选区协作：选中画布内容，点输入框旁的「加入对话」，文字和截图就会进入草稿。带着选区继续提问，也可以让 DSH 直接创建、修改白板，批量添加脑图节点 ✨

界面跟随 DSH 切换深浅色，白板保存在本机，还内置了六页可以直接编辑的体验介绍。项目已开源，在 GitHub 搜索「moki-canvas-for-dsh」就能找到，欢迎来试试，也欢迎反馈使用感受。
